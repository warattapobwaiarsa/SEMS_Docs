# 🚀 Deployment & Operations

เก็บเอกสารและคู่มือที่เกี่ยวข้องกับการนำระบบขึ้นใช้งานจริงและการดูแลรักษา:
- **Deployment Guide:** ขั้นตอนการ Deploy ระบบ (Runbook) และการตั้งค่า Environment ต่างๆ
- **Admin Guide:** คู่มือการตั้งค่าและการควบคุมระบบหลังบ้านสำหรับผู้ดูแลระบบ
- **User Manual:** คู่มือการใช้งานสำหรับผู้ใช้ทั่วไป
