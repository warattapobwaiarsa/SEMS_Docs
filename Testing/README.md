# 🧪 Testing & Quality Assurance

เก็บเอกสารเกี่ยวกับการทดสอบระบบเพื่อควบคุมคุณภาพของซอฟต์แวร์:
- **Test Plan & Test Cases:** แผนงานทดสอบและตารางกรณีทดสอบฟังก์ชันต่างๆ
- **UAT Scenario:** ชุดการทดสอบสำหรับจำลองการใช้งานจริงเพื่อให้ลูกค้า/ผู้ใช้งานร่วมทำ UAT
- **UAT Sign-off:** บันทึกการอนุมัติและลงนามผ่านการทดสอบ UAT
