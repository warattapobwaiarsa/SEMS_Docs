# 🧠 Areas of Knowledge

เก็บโน้ตความรู้หรือเทคนิคต่างๆ ที่จำเป็นและต้องปรับปรุงอย่างต่อเนื่อง ไม่ผูกมัดเฉพาะโครงการนี้โครงการเดียว:
- **Frontend:** เทคนิค React, CSS/Tailwind, UI libraries
- **Backend:** เทคนิค Node.js, Database optimization, Security/Auth
- **DevOps:** ความรู้ Docker, CI/CD, Git workflows, Cloud configuration
- **Best Practices:** แนวคิดการเขียนโค้ดที่สะอาดและมีประสิทธิภาพ (Clean Code, Refactoring)
